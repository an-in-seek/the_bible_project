# 1음절 명사 허용 목록
# 설계 문서: docs/bible/word-frequency-design.md §4.2
#
# 조사를 뗀 줄기가 1음절이면 원칙적으로 버리지만, 이 목록에 있으면 살린다.
# 이 목록이 없으면 상위권이 '땅에(130)'·'주의(755)' 같은 형태로 남고,
# 시편의 최상위 단어 '주'(1235)는 통째로 사라진다. (프로토타입 실측)
#
# 빠뜨리면 그 단어가 안 나오는 게 아니라 **조사 개수만큼 갈라진다.** 창세기 실측:
#   롯  -> 롯이 12 / 롯을 6 / 롯의 5 / 롯도 4 / 롯과 3  (한 인물이 표제어 5개)
#   몸  -> 몸을 7 / 몸에 4 / 몸과 3                     (어휘의 '몸' 은 0회)
#   떼  -> 떼가 7 / 떼를 5 / 떼로 3                     (어휘의 '떼' 는 1회)
# 그러니 어휘(bible_word)에 1음절 표제어를 넣을 때는 이 파일도 같이 봐야 한다.
# 두 목록은 코드로 연결돼 있지 않다 — 토크나이저는 DB 를 보지 않는다.
#
# 반대로 함부로 넣으면 멀쩡한 2음절 명사가 깎인다. 넣기 전에 "그 글자로 끝나는 2음절
# 단어 + 조사" 가 실재하는지 확인한다. 그래서 뺀 것들:
#   실 -> '실과'(열매)가 '실' 로 깎인다      함 -> 함(노아의 아들)과 '하다' 의 명사형이 섞인다
#   태 -> '태도' 가 '태' 로 깎인다           들 -> 들(들판) / 듣다 / 복수 접미사가 겹친다
