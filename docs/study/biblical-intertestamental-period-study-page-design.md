## 1. 개요 (Overview)

### 1-1. 페이지 목적

말라기 이후부터 마태복음 이전까지, 약 400년의 **신구약 중간기**를 다루는 학습 페이지이다.

이 페이지의 목표는 중간기의 사건을 나열하는 것이 아니라, **"신약의 세계가 어떻게 만들어졌는가"** 를 설명하는 것이다.
사용자가 신약을 펼쳤을 때 갑자기 등장하는 회당, 공회(산헤드린), 바리새인, 사두개인, 헬라어, 사마리아인, 헤롯 왕가, 로마 총독이 어디에서 왔는지 이해하는 것이 이 페이지의 성공 기준이다.

> 구약을 다 읽고 신약을 펴면 무대가 완전히 바뀌어 있다. 그 무대 전환이 일어난 400년이 이 페이지의 주제다.

### 1-2. 기존 페이지와의 관계 (중요)

**이미 `/web/study/history/intertestamental` 경로에 "신구약 중간사" 시대 페이지가 존재한다.**
`HistoryDummyData`(`HistoryViewResponse.kt:100-104`)에 `intertestamental` 시대(B.C. 400~4)가 정의되어 있고, 다음 3개 사건이 등록되어 있다(`:518-541`).

| 사건 id              | 제목        | 연대            |
|--------------------|-----------|---------------|
| `event-alexander`  | 알렉산더의 정복  | B.C. 333년     |
| `event-maccabees`  | 마카비 혁명    | B.C. 167~164년 |
| `event-roman-rule` | 로마의 지배 시작 | B.C. 63년      |

따라서 신규 페이지는 **같은 내용을 다시 만들지 않는다.** 역할을 다음과 같이 분리한다.

| 페이지                                        | 성격                  | 다루는 것                                       |
|--------------------------------------------|---------------------|---------------------------------------------|
| `/web/study/history/intertestamental` (기존) | 11개 시대 중 하나의 **요약** | 대표 사건 3개, 성경 역사 전체 흐름 속 위치                  |
| `/web/study/intertestamental` (신규)         | 중간기 **단독 심화**       | 통치 세력 교체 + 7개 변화 축 + 유대 분파 + 신약의 무대 + 신약 연결 |

- 두 페이지의 상호 링크는 **§11-4 한 곳에서만 정의**한다. 신규 페이지에서는 하단 `관련 학습 페이지` 섹션에 배치한다(상단 중복 배치 금지).
- 사건 3개는 신규 페이지에서도 등장하지만, 신규 페이지에서는 사건 자체가 아니라 **그 사건이 만든 변화**를 서술한다.
  (예: 알렉산더의 정복 → 코이네 헬라어의 확산 → 70인역 → 신약이 헬라어로 기록됨)
- **기존 페이지의 서술 수준에서 후퇴하지 않는다.** 예컨대 기존 데이터는 로마 지배를 "하스몬 왕조의 내분을 틈타"라고 인과까지 적고 있으므로, 신규 페이지도 최소 그만큼은 설명한다.

### 1-4. 대상 사용자

- 구약을 읽고 신약으로 넘어가며 배경이 끊긴다고 느끼는 일반 성도
- 복음서의 바리새인·사두개인 논쟁, 특히 **안식일 논쟁이 왜 그렇게 격렬한지** 이해하고 싶은 사용자
- 소그룹·제자훈련에서 중간기를 한 번에 정리해 주어야 하는 교사, 리더, 설교 준비자
- 수전절, 회당, 공회, 70인역, 사마리아인 같은 용어의 출처를 확인하려는 사용자

### 1-5. 핵심 가치

- **연표 암기가 아니라 무대 전환의 이해**를 목표로 한다.
- 중간기를 "아무 일도 없던 400년"이 아니라 **"신약을 가능하게 만든 400년"** 으로 제시한다.
- 성경 본문·역사 자료·교단별 견해가 갈리는 항목을 **명확히 구분해서 표시**한다(§2).
- 모든 설명은 "그래서 신약 어디에서 만나는가"로 착지한다.

## 2. 용어와 서술 원칙 (필수)

이 페이지는 이 프로젝트의 다른 학습 페이지보다 **교리적·교단적 민감도가 높다.** 다음 원칙을 서술과 UI 문구 모두에 적용한다.

### 2-1. "침묵기"라는 표현 주의

중간기는 흔히 "400년의 침묵기"로 불리지만, 이 표현은 **하나님이 일하지 않으셨다는 뜻이 아니다.** 정경으로 인정되는 예언서의 기록이 중단된 기간을 가리키는 관용적 표현이다.

화면에는 다음 세 문장을 함께 둔다.

1. "침묵"은 **예언의 중단**을 뜻하며, 하나님이 일하지 않으셨다는 뜻이 아니다.
2. **문헌의 침묵도 아니다.** 이 기간에 유대 묵시 문학과 지혜 문학이 활발히 기록되었다.
3. 이 인식은 후대의 해석이 아니라 **당대 유대인의 자기 인식**이었다. 특히 마카비상 9:27이 "선지자가 나타나지 않게 된 날 이후"라고 **직접 진술**하며, 4:46과 14:41은 "선지자가 올 때까지"라는 표현으로 그 부재를 **전제**한다.
   `외경·제2정경`
   ⚠️ 세 구절의 성격이 다르므로 **"셋 모두 선지자가 없다고 진술한다"고 쓰지 않는다.** 직접 진술은 9:27뿐이다.

- "하나님이 떠나 계셨다", "버려진 시기" 같은 표현은 쓰지 않는다.
- 3번 인용에는 반드시 `외경·제2정경` 배지를 붙인다(§2-2).

### 2-2. 외경·제2정경은 정답을 정하지 않는다

마카비서, 집회서, 토빗 등은 **교단에 따라 정경 범위가 다르다.**

| 전통     | 위치                                         |
|--------|--------------------------------------------|
| 개신교    | 정경에 포함하지 않음 (외경)                           |
| 로마 가톨릭 | 제2정경으로 포함 (트리엔트 공의회, 1546)                 |
| 정교회    | 전통에 따라 범위가 더 넓음 (에스드라1서, 마카비3서, 므낫세의 기도 등) |

- 화면에서는 **"교단에 따라 정경 범위가 다릅니다"** 를 명시하고, 특정 전통을 기준으로 단정하지 않는다.
- 정경 목록 자체를 판정하는 UI(체크·X 표시 등)는 만들지 않는다. 표 형태로 병기만 한다.

#### 개신교 독자의 긴장을 정면으로 해소한다

이 페이지는 개신교 독자에게 **"당신이 정경으로 보지 않는 책에서 나온 역사(수전절)"** 를 받아들이라고 요구한다. 이 긴장을 덮지 않고 다음 문구로 정면 해소한다. **이 문단은 수전절 카드와 하스몬 상세 패널 두 곳에 노출한다.**

> 마카비서는 개신교에서 정경으로 보지 않지만, 여기서는 **성경이 아니라 역사 자료로 인용**합니다.
> 같은 사건은 유대 역사가 **요세푸스**(『유대 고대사』 12권)에도 독립적으로 기록되어 있습니다.
> 정경 범위에 대한 판단과, 그 시기에 실제로 무슨 일이 있었는지에 대한 이해는 별개의 문제입니다.

#### 위경(Pseudepigrapha)은 다루지 않는다

에녹1서·희년서 등 위경은 **개신교·로마 가톨릭·대부분의 정교회 전통에서 정경으로 보지 않는 별개 범주**이므로 이 페이지에서 다루지 않는다.

> ⚠️ **"어느 교단도 정경으로 보지 않는다"고 쓰지 않는다.** **에티오피아 정교회 테와히도 교회는 에녹1서와 희년서를 구약 정경에 포함한다.** 에녹1서의 온전한 사본이 게에즈(에티오피아어)본으로만 남아 있는 것이 바로 이 교회가 성경으로 필사·보존했기
> 때문이다. 위 §2-2 표의 "정교회 — 전통에 따라 범위가 더 넓음"과 충돌하지 않도록 표현에 주의한다.

(유다서 1:14-15가 에녹1서를 인용하는 문제는 이 페이지의 범위를 넘어선다. §14 후속 후보로 둔다.)

### 2-3. 정보 유형 배지

`bible-history-map.md` §4.1이 정의한 배지 어휘를 기준으로 삼되, **이 페이지의 사용 범위를 정확히 밝힌다.**

| 배지         | 의미               | 예                   | 출처 문서        |
|------------|------------------|---------------------|--------------|
| `성경 본문`    | 정경 본문에서 직접 확인 가능 | 단 8:21의 "헬라 왕"      | §4.1 그대로     |
| `역사 자료`    | 역사 문헌·고고학으로 확인   | 폼페이우스의 예루살렘 점령      | §4.1 그대로     |
| `유력한 추정`   | 유력하지만 확정되지 않음    | 에세네파와 쿰란 공동체의 관계    | §4.1 그대로     |
| `여러 견해 존재` | 연대·해석에 복수 견해     | 회당의 기원, 산헤드린의 형성 시점 | §4.1 그대로     |
| `외경·제2정경`  | 교단별 정경 범위가 다른 문헌 | 마카비상·하              | **이 페이지 신설** |

- `bible-history-map.md` §4.1의 4개 배지를 **모두 사용한다.** 여기에 이 페이지 전용으로 `외경·제2정경` 하나를 추가한다.
- `유력한 추정`과 `여러 견해 존재`를 혼동하지 않는다. **유력한 단일 견해가 있으면 `유력한 추정`, 견해가 갈라져 있으면 `여러 견해 존재`** 이다.
- 배지는 색상만으로 구분하지 않고 **항상 텍스트를 포함**한다(§8).
- 상세 패널을 여는 모든 항목, 그리고 §5-9의 모든 카드는 배지를 최소 1개 가진다.

### 2-4. 요세푸스는 사료로 명시한다

§5-6 분파 표의 서술은 거의 전부 요세푸스에서 온다. `역사 자료` 배지가 사실상 요세푸스에 기대고 있으므로, 출처와 한계를 함께 밝히는 것이 배지 정책과 일관된다. 분파 표 하단에 다음을 고정 배치한다.

> 아래 서술의 상당 부분은 유대 역사가 **요세푸스**(A.D. 37~100경)의 기록에 근거합니다.
> 그는 A.D. 70년 이후 로마 독자를 향해 쓴 유대인으로, 분파들을 헬라 '철학 학파'에 빗대어 소개합니다.
> 가장 중요한 사료이지만, 그 자체로 하나의 관점입니다.

### 2-5. 연대 표기

- 이 페이지의 모든 연대는 **대략적인 B.C. 기준**이며, 자료에 따라 달라질 수 있음을 Intro에 명시한다.
- 중간기 범위는 기존 `HistoryDummyData`와 동일하게 **B.C. 400~4**로 표기해 두 페이지 간 표기 충돌을 만들지 않는다.
  (말라기 기록 연대를 B.C. 430년경으로 보는 견해도 있으나, 프로젝트 내 표기를 우선한다.)
- **전투 연도와 지배권 이양 연도를 혼동하지 않는다.** 관례적 표기를 유지하되 각주로 구분한다(§6-1).
- 화면에 `0년`을 표시하지 않는다.

### 2-6. 다니엘서 저작 연대에 대한 중립 선언

다니엘 8·11장을 셀류커스·안티오쿠스 4세와 연결하는 것은 **널리 인정되는 대응**이다. 논쟁은 그 대응 자체가 아니라 **(a) 다니엘서의 기록 연대**와 **(b) 안티오쿠스를 넘어 종말론적으로도 가리키는지**에 있다. 한국 개신교 독자에게 가장 민감한
지점이므로, 해당 상세 패널에 다음을 명시한다.

> 이 페이지는 **다니엘서의 기록 연대 문제에 대해 어느 한쪽 입장을 취하지 않습니다.**

- 연대 논쟁을 우회하는 안전한 앵커로 **단 8:21("곧 헬라 왕이요")** 을 쓴다. 본문이 "헬라"를 직접 명시하므로 `성경 본문` 배지를 정당하게 붙일 수 있다.

## 3. study.html 메뉴 변경

### 3-1. 현재 상태

원래 `study.html`의 카드 그리드 최하단에는 **`🎓 성경 강의` 준비중 카드**가 있었다(링크 없는 `coming-soon` 카드).

## 5. 화면 구성

### 5-1. 렌더링 방식 (먼저 읽을 것)

**이 페이지의 콘텐츠는 전부 Thymeleaf 정적 마크업으로 작성한다. JS는 상세 패널 토글만 담당한다.**

| 영역                                                                          | 렌더링                                                 |
|-----------------------------------------------------------------------------|-----------------------------------------------------|
| Intro, Bridge Strip, 통치 세력 카드, 변화 축, 분파 표, 신약의 무대, 신약 연결, 침묵이 끝나는 지점, 관련 링크 | **Thymeleaf 정적 마크업**                                |
| 통치 세력 상세 패널                                                                 | **Thymeleaf 정적 마크업** (각 통치 세력마다 `hidden` 상태로 미리 렌더) |
| 상세 패널 열기/닫기                                                                 | **JS** (`hidden` 속성 토글 + `aria-expanded` 갱신)        |

근거:

1. `.claude/rules/frontend.md`는 **"Server-side rendering (Thymeleaf) is the default"** 를 명시한다.
2. §12의 SEO 키워드(회당, 공회, 바리새인, 사두개인, 70인역, 수전절, 사마리아인)가 **전부 이 콘텐츠 안에 있다.** JS로 렌더하면 서버가 내려주는 HTML은 빈 `<section>` 껍데기가 된다.
3. 이 페이지에는 서버 조회도 사용자 입력도 없다. **JS 데이터 배열을 둘 이유가 없다.**

> 이 결정으로 `ITP_RULERS` 같은 JS 데이터 배열은 **사용하지 않는다.** 콘텐츠의 단일 출처는 §6의 표이며, 구현자는 §6을 템플릿 마크업으로 옮긴다.

#### 검토한 대안: 컨트롤러 데이터 + `th:each`

콘텐츠를 Kotlin 구조체로 두고 `Model`로 넘겨 `th:each`로 반복하는 방식도 **위 두 근거(SSR·SEO)를 똑같이 만족한다.** 데이터가 한 곳에 모이고 템플릿이 짧아진다는 장점도 분명하다. 그럼에도 손으로 쓴 정적 마크업을 택한 이유는 다음과
같다.

- **학습 정적 페이지 선례가 전부 무모델이다.** `StudyWebController.kt`의 기존 12개 라우트가 모두 `Model` 주입 없이 뷰 이름만 반환한다. 이 페이지 하나만 다른 구조를 쓰면 학습 모듈 안에서 예외가 된다.
- 이 콘텐츠는 **운영자가 편집하지 않는다.** 구조체의 주된 이점(편집 용이성)이 크게 작용하지 않는다.
- 항목마다 형태가 다르다(상세 bullet 수, `관련 본문`·`주의`의 유무). 구조체로 만들면 nullable 필드가 늘어 오히려 복잡해진다.

**트레이드오프는 인정한다.** 템플릿이 길어지고(§6의 콘텐츠를 옮기면 700줄 이상 예상), §5의 도해·요약과 §6의 원본 사이에 표기가 어긋날 여지가 생긴다. 후자는 §6 우선 규칙으로 방어한다.

§14의 후속 항목(사전 링크, 디아스포라 축 승격, 정경 3부 구조)으로 콘텐츠가 계속 늘어나면 **`th:each`로의 전환을 재검토한다.** 마크업 → `th:each`는 기계적인 리팩터링이므로 나중에 해도 비용이 크지 않다.

### 5-5. Ruler Timeline (통치 세력 교체)

중간기의 뼈대는 **"누가 유대 땅을 다스렸는가"** 이다. 가로 스크롤 스트립으로 표현한다.
콘텐츠는 §6-1이 단일 출처다.

```text
◀ 스크롤 ──────────────────────────────────────────────────────▶

┌─────────┬──────────┬──────────┬──────────┬──────────┬─────────┐
│ 페르시아 │ 알렉산더 │ 프톨레미  │ 셀류커스  │ 하스몬    │  로마   │
│         │ ·디아도코이│         │          │          │         │
│ ~B.C.333│ 333~301  │ 301~198  │ 198~167  │ 167~63   │ 63~     │
│ 대제사장 │ 헬라어    │ 70인역   │ 성전 모독 │ 독립과    │ 총독과   │
```

#### 통치 세력 카드 마크업

```html

<li class="itp-ruler-item">
  <button type="button" class="itp-ruler-card"
          aria-expanded="false" aria-controls="itpRulerDetail-ptolemaic">
    <span class="itp-ruler-name">프톨레미 왕조</span>
    <span class="itp-ruler-subtitle">애굽</span>
    <span class="itp-ruler-range">B.C. 301~198</span>
    <span class="itp-ruler-keyword">70인역 번역 시작</span>
  </button>
  <div id="itpRulerDetail-ptolemaic" class="itp-ruler-detail" hidden>
    <!-- 상세 패널 내용 (아래 표) -->
  </div>
</li>
```

- 카드의 4번째 줄은 `itp-ruler-keyword` — **한 줄짜리 짧은 키워드**다. §6-1의 `카드 키워드` 열이 출처이며, 문장형 `요약`과 다른 필드다.
- 상세 패널은 각 카드 **바로 아래**에 `hidden` 상태로 미리 렌더한다. 페이지 하단의 공용 패널을 쓰지 않는다 — 공용 패널은 `aria-live` 남용과 포커스 이동 문제를 만든다.

| 주의         | 연대·해석 주의 문구 (있는 경우만) | §6-1 `주의`    |
| 추가 노출      | 지정된 절의 문단 (있는 경우만)   | §6-1 `추가 노출` |

- `관련 본문`, `주의`가 비어 있으면 **해당 블록 자체를 렌더하지 않는다.** 빈 제목만 남기지 않는다.

### 5-6. Change Tracks (변화 축) — 핵심 섹션

**이 페이지의 존재 이유이자, 기존 성경 역사 페이지와의 결정적 차이다.**
시간이 아니라 **주제**로 400년을 자른다. 각 트랙은 `중간기 이전 → 신약 시대 → 왜 → 신약 접점` 4단으로 구성한다.

콘텐츠 전문은 **§6-2가 단일 출처**다. 7개 트랙 전부의 카피가 그 표에 있다.

#### 토글 없음

**변화 축은 접히지 않는다.** 토글 버튼도, `aria-expanded`도, `<details>`도 쓰지 않는다.
이 섹션은 페이지의 본론이므로 사용자가 열어야만 보이면 안 된다. 항상 펼쳐진 정적 마크업이다.

#### 마크업

```html

<article class="itp-track">
  <h3 class="itp-track-title">
    <span class="itp-track-index" aria-hidden="true">1</span>언어
  </h3>
  <div class="itp-track-compare">
    <div class="itp-track-before">
      <p class="itp-track-label">중간기 이전</p>
      <p>히브리어 + 아람어(이미 확산 중)</p>
    </div>
    <div class="itp-track-arrow" aria-hidden="true">→</div>
    <div class="itp-track-after">
      <p class="itp-track-label">신약 시대</p>
      <p>히브리어(예배·경전) + 아람어(일상) + 코이네 헬라어(공용어)</p>
    </div>
  </div>
  <p class="itp-track-why">…</p>
  <ul class="itp-track-refs"><!-- 신약 접점 링크 --></ul>
</article>
```

- `.itp-track-arrow`는 `aria-hidden`이므로, 모바일에서는 **CSS `transform: rotate(90deg)`** 로 처리한다. 텍스트 노드를 교체하는 JS는 쓰지 않는다.
- 스크린 리더에는 `중간기 이전` / `신약 시대` 라벨 텍스트로 순서가 전달된다.
- **`references`가 비어 있으면 `<ul class="itp-track-refs">` 자체를 렌더하지 않는다.** **트랙 2·6만** 본문 인용이 없고 산문 설명만 있다(§6-2의 `신약 접점` 열 참고).
  ⚠️ **트랙 7에는 인용이 있다**(막 2:23-28, 막 7:1-5). 이 두 링크는 §1-4가 명시한 "안식일 논쟁이 왜 그렇게 격렬한지"에 답하는 페이지 내 유일한 지점이므로 **누락하면 안 된다.**

### 5-7. Sects Table (유대 분파 비교)

복음서 이해에 직접 필요한 섹션이다. 콘텐츠는 **§6-3이 단일 출처**다.

#### 표 상단 고정 안내 (필수)

> 아래 다섯 집단은 성격이 같지 않습니다.
> **바리새·사두개·에세네는 신앙 노선의 차이**이고, **헤롯당과 열심당은 정치적 입장의 차이**입니다.
> 요세푸스가 유대 '철학(분파)'으로 꼽은 것은 앞의 셋입니다.

#### 표 하단 고정 안내 (필수)

§2-4의 요세푸스 사료 안내를 배치한다.

#### 정확성 주의

- **에세네파는 신약에 직접 언급되지 않는다.** 표에 그대로 명시한다. "세례 요한이 에세네파였다"는 식의 추정은 서술하지 않는다.
- **에세네파와 쿰란 공동체(사해사본)의 관계는 `유력한 추정`이다.** 동일시를 단정하지 않는다.
- **열심당은 A.D. 66년 유대 전쟁 무렵에 조직된 집단이다.** 예수님의 사역 당시 바리새인·사두개인과 같은 층위의 분파로 서술하지 않는다(§6-3 주석 필수).
- 바리새인을 "위선자"로, 사두개인을 "타협자"로 낙인찍는 서술을 하지 않는다.
  → **정치 성향 열에 "타협"이라는 단어를 쓰지 않는다.** "현실적 협력"으로 쓴다.
- 표는 `<table>`로 작성한다. 모바일에서 가로 스크롤을 허용하되(`overflow-x: auto`) **열을 줄여 정보를 삭제하지 않는다.**
- 정보 유형 배지는 별도 열을 만들지 않고 **쟁점이 있는 셀 안에 인라인으로** 배치한다(별도 열은 모바일 가로 폭을 과도하게 만든다).
- **배지에는 반드시 범위를 함께 적는다** (`쿰란 관계: 유력한 추정`, `기원: 여러 견해 존재`).
  **배지는 그 쟁점이 실제로 걸려 있는 셀에 붙인다.** 확실한 진술이 담긴 셀에 붙이면 뜻이 뒤집힌다 — 예컨대 사두개인의 "구전 전승 부인"은 요세푸스로 뒷받침되는 **확실한** 항목이고, 쟁점은 **정경 범위**(모세오경만 인정했는가)다.
  범위 없이 분파 이름 옆에만 붙이면 **"이 분파의 존재 자체가 불확실하다"로 읽힌다.** 에세네파의 존재는 요세푸스·필론·대 플리니우스가 독립적으로 증언하는 확실한 사실이고, 쟁점은 **쿰란 공동체와의 동일시**다. 열심당도 마찬가지로 존재나 A.D. 66년 조직
  시점이 아니라 **눅 6:15 '셀롯'이 소속을 뜻하는지**가 쟁점이다.
  배지 체계의 취지가 "각주를 읽지 않아도 뜻이 통한다"이므로(§2-3), 범위 표기를 생략하지 않는다.

### 5-8. NT Stage (신약의 무대)

§1-1이 약속한 "사마리아인, 헤롯 왕가, 로마 총독이 어디에서 왔는가"에 답하는 섹션이다.
**중간기가 만들어 낸, 복음서를 펼치면 바로 보이는 세 가지**를 카드로 제공한다. 콘텐츠는 **§6-4가 단일 출처**다.

| 카드           | 한 줄 요약                        |
|--------------|-------------------------------|
| 사마리아인과 그리심 산 | 유대인과 사마리아인이 상종하지 않게 된 내력      |
| 헤롯 대왕과 헤롯 성전 | 복음서의 성전은 헤롯이 대대적으로 개축한 제2성전이다 |
| 로마의 통치 구조    | 총독·분봉왕·세금이 한 화면에 등장하는 이유      |

> **"복음서의 성전은 스룹바벨 성전이 아니다"라고 쓰지 않는다.** 헤롯은 성전을 헐고 새로 지은 것이 아니라 제2성전을 대규모로 개축·확장했고, 유대 전통도 요세푸스도 이를 제2성전의 **연속**으로 취급한다(제3성전이라 부르지 않는다). 엄밀히 말하면 복음서의
> 성전도 여전히 제2성전이다.

- 이 섹션은 §5-6(변화 축)이 다루는 "제도의 변화"와 달리 **"장면의 배경"** 을 다룬다. 두 섹션의 역할이 겹치지 않도록, 여기서는 제도 설명을 반복하지 않고 신약 장면과의 연결만 서술한다.

#### 카드 구성 (§5-5 상세 패널과 동일한 순서 규칙)

| 순서 | 섹션        | 출처                     | 비어 있으면         |
|----|-----------|------------------------|----------------|
| 1  | 제목        | §6-4 카드명               | —              |
| 2  | 한 줄 요약    | §6-4 `요약`              | —              |
| 3  | 상세 bullet | §6-4 `상세`              | —              |
| 4  | 정보 유형 배지  | §6-4 `정보 유형` (§6-6 순서) | —              |
| 5  | 신약 접점 링크  | §6-4 `신약 접점`           | 블록 자체를 렌더하지 않음 |
| 6  | 주의        | §6-4 `주의`              | 블록 자체를 렌더하지 않음 |

- **카드 3개의 순서 규칙은 동일하다.** §6-4의 항목별 서술 순서가 달라 보이더라도 화면 순서는 이 표를 따른다.
- **카드 간 주제가 겹치지 않게 한다.** 헤롯 사후 영토 분할과 아켈라오 폐위는 **카드 3(로마의 통치 구조)** 에만 둔다. 카드 2는 헤롯 개인과 성전 건물에 한정한다.
- **배지는 §5-7과 같은 규칙을 따른다.** 카드의 `정보 유형`은 **상세 bullet 전체에 해당하는 것만** 넣는다. 쟁점이 `주의` 필드 하나에만 걸려 있으면 카드 레벨이 아니라 **그 문장에 범위 표기와 함께 인라인으로** 붙인다(예: 카드 2의
  `마 2장 해석: 여러 견해 존재`). 카드 레벨에 붙이면 독자가 배지를 카드 헤드라인에 매핑해 **확정 사실까지 쟁점으로 읽는다.**
- §6-1이 `관련 본문`이라 부르는 필드를 §6-4는 `신약 접점`이라 부른다. 같은 것이며, 명칭 차이는 섹션 성격 때문이다.

### 5-9. NT Bridge (신약에서 이렇게 만납니다)

페이지의 착지점. 중간기 산물이 신약 본문에서 실제로 등장하는 지점을 링크 카드로 제공한다.
콘텐츠는 **§6-5가 단일 출처**다.

> **수전절은 이 페이지에서 가장 강력한 연결 고리다.** 요한복음 10:22의 "수전절"은 마카비 혁명(B.C. 164) 때의 성전 정결을 기념하는 절기다. 중간기를 모르면 그냥 지나가는 한 단어가, 중간기를 알면 400년을 압축한 문장이 된다.

- 수전절 카드는 `highlight` 스타일(강조 테두리 + 크기 확대)로 배치한다.
- 수전절 카드에는 **`성경 본문`(요 10:22)과 `외경·제2정경`(마카비상 4장) 배지를 나란히** 붙이고, §2-2의 정경 안내 문단을 함께 노출한다. 페이지의 대표 항목에서 §2-2 정책을 실제로 시연하는 자리다.

### 5-10. Closing (침묵이 끝나는 지점)

§2-1이 세운 "침묵" 프레임을 닫는다. 짧은 마무리 문단 하나로 충분하다.

> 400년의 침묵은 갑자기 끝났습니다.
> 성전에서 향을 피우던 제사장 사가랴에게 천사가 나타났고(눅 1:8-13),
> 사가랴는 성령의 충만함을 입어 **예언했습니다**(눅 1:67).
> 성전에서는 **"안나라 하는 선지자"** 가 아기 예수를 알아보았고(눅 2:36),
> 마침내 **"하나님의 말씀이 빈 들에서 사가랴의 아들 요한에게 임했습니다"**(눅 3:2).
> 구약 선지서가 하나님의 말씀이 임하는 것을 서술하던 바로 그 문구가, 400년 만에 다시 등장합니다.
> 무대는 400년에 걸쳐 준비되었고, 이제 막이 오릅니다.

| 링크      | 딥링크                             |
|---------|---------------------------------|
| 누가복음 1장 | `bookOrder=42, chapterNumber=1` |
| 누가복음 2장 | `bookOrder=42, chapterNumber=2` |
| 누가복음 3장 | `bookOrder=42, chapterNumber=3` |

- **눅 2:36("선지자")과 눅 3:2("하나님의 말씀이 … 임한지라")가 이 섹션의 핵심이다.** "침묵이 끝났다"를 서술이 아니라 **본문으로 증명**하는 두 구절이므로 요약하거나 생략하지 않는다.

- **세례 요한을 특정 분파와 연결하지 않는다**(§5-7 주의).

## 6. 콘텐츠 (단일 출처)

**이 장의 표가 화면 문구의 단일 출처다.** §5의 서술과 충돌하면 이 장을 따른다.
구현자는 이 표를 Thymeleaf 정적 마크업으로 옮긴다(§5-1).

### 6-0. 필드 종류 — 화면에 나가는 것과 아닌 것

이 장에는 **화면 문구**와 **구현자에게 주는 지시**가 함께 있다. 그대로 옮겨 적는 방식이므로 구분이 중요하다.

| 필드                                               | 화면 출력                                     |
|--------------------------------------------------|-------------------------------------------|
| `요약` · `상세` · `정보 유형` · `관련 본문` · `신약 접점` · `주의` | **출력한다**                                  |
| `추가 노출`                                          | 지정된 다른 절(§2-2, §2-6 등)의 문단을 그 자리에 함께 출력한다 |
| **〔구현 지시 · 화면 출력 금지〕**                           | **출력하지 않는다.** 구현자가 읽고 판단하는 내용이다           |

> 〔구현 지시〕 항목은 대부분 **검토에서 오류로 지적되어 고쳐진 지점의 재발 방지용**이다. 지우지 말고 문서에 남겨 둔다.
> `주의` 필드 안에 "§2-6을 함께 노출합니다" 같은 **지시문을 섞어 쓰지 않는다.** 그런 내용은 `추가 노출`로 분리한다.

### 6-1. 통치 세력 (6개)

| # | slug          | 이름          | 부제     | 연대           | 카드 키워드     | 요약                                                 |
|---|---------------|-------------|--------|--------------|------------|----------------------------------------------------|
| 1 | `persian`     | 페르시아 말기     | —      | ~B.C. 333    | 대제사장 자치    | 성전 재건 이후 대제사장을 중심으로 한 자치가 이어졌습니다.                  |
| 2 | `hellenistic` | 알렉산더와 디아도코이 | 헬라     | B.C. 333~301 | 헬라어 확산     | 알렉산더의 정복 이후 후계자들이 근동을 두고 다투었습니다.                   |
| 3 | `ptolemaic`   | 프톨레미 왕조     | 애굽     | B.C. 301~198 | 70인역 번역 시작 | 비교적 안정된 시기였고, 알렉산드리아에서 구약이 헬라어로 번역되기 시작했습니다.       |
| 4 | `seleucid`    | 셀류커스 왕조     | 수리아    | B.C. 198~167 | 성전 모독      | 헬라화 압박이 심해지고 안티오쿠스 4세가 성전을 모독했습니다.                 |
| 5 | `hasmonean`   | 하스몬 시대      | 독립과 내분 | B.C. 167~63  | 유일한 독립기    | 마카비 혁명으로 시작해 약 80년의 독립을 누렸으나, 후기의 내분이 로마를 불러들였습니다. |
| 6 | `roman`       | 로마          | —      | B.C. 63~     | 총독과 헤롯     | 폼페이우스의 점령 이후 로마가 유대를 다스렸고, 신약의 정치 지형이 완성되었습니다.     |

> `slug`는 상세 패널 id(`itpRulerDetail-{slug}`)에 쓰이며, §14의 URL 쿼리 공유(`?ruler=hasmonean`)를 도입할 경우 **그대로 URL 계약이 된다.** 임의로 바꾸지 않는다.

> **카드 키워드와 부제는 다른 필드다.** 하스몬의 부제는 `독립과 내분`, 카드 키워드는 `유일한 독립기`다. §5-5의 ASCII 도해는 폭 때문에 축약된 표현을 쓰므로, **충돌 시 이 표를 따른다.**

#### 상세 · 정보 유형 · 관련 본문 · 주의

**1. 페르시아 말기 (~B.C. 333)**

#### 각주 (표 아래 배치)

- **바리새인**: 마카비 시대의 '하시딤'(경건한 자들)에서 갈라져 나왔다고 보는 견해가 널리 소개되지만, 자료가 충분하지 않아 학자마다 견해가 다릅니다.
- **사두개인**: 사두개인이 모세오경만을 성경으로 인정했다는 설명이 널리 퍼져 있으나, 이는 후대 문헌에 근거한 것으로 논란이 있습니다. 자료상 분명한 것은 **구전 전승의 권위를 인정하지 않았다는 점**입니다. (부활·천사 부인은 행 23:8, 막 12:18로
  뒷받침됩니다.)
- **에세네파**: 신약에 한 번도 등장하지 않습니다(요세푸스·필론·대 플리니우스에만 나옵니다). 쿰란 공동체(사해사본)와의 관계는 널리 받아들여지지만 확정된 것은 아닙니다. 요세푸스가 전하는 믿음은 **영혼 불멸**이며, 육체 부활 여부에는 견해가 갈립니다.
- **열심당**: **A.D. 66년 유대 전쟁 무렵에 조직된 집단**으로, 예수님의 사역 당시 바리새인·사두개인과 같은 층위의 분파로 존재했다고 보기는 어렵습니다. 눅 6:15의 '셀롯이라 하는 시몬'은 마가복음에서 '가나안인 시몬'(막 3:18, 아람어로 '열심인
  자')으로 불리며, 조직 소속보다 **'열심'이라는 별명**으로 이해하는 견해가 유력합니다. 다만 반로마 저항의 흐름 자체는 A.D. 6년 갈릴리 유다의 봉기 이후 계속 이어졌습니다.
- `—` 표시는 **해당 항목이 이 집단을 규정하는 기준이 아니라는 뜻**입니다(정보 없음이 아닙니다). 헤롯당과 열심당은 신앙 노선이 아니라 정치적 입장으로 묶인 집단이기 때문입니다.

### 6-4. 신약의 무대 (3개)

**1. 사마리아인과 그리심 산**

- 요약: 유대인과 사마리아인이 상종하지 않게 된 내력.
- 상세:
    - 사마리아인들은 그리심 산에 독자적인 성전을 세우고 그곳에서 예배했습니다.
    - 하스몬 왕 요한 힐카누스가 B.C. 2세기 후반에 그리심 산 성전을 파괴했습니다.
    - 이 사건이 복음서가 전제하는 유대-사마리아 적대를 굳혔습니다.
- 정보 유형: `성경 본문` `역사 자료` `여러 견해 존재`
- 주의: 파괴 시점은 요세푸스의 기록에 따라 **B.C. 128년경**으로 보는 견해가 널리 쓰이지만, 그리심 산 발굴 결과를 근거로 **B.C. 110년경**으로 보는 견해도 있습니다. 파괴의 주체가 요한 힐카누스라는 점에는 이견이 없습니다.
- 〔구현 지시 · 화면 출력 금지〕 **사마리아인의 기원(왕하 17장의 이주 정책 서사)은 다루지 않는다.** 이는 유대 측 논쟁 문헌의 성격이 강하고, 사마리아인 자신은 북이스라엘 지파의 후예로 자처한다. 다루려면 반드시 양쪽 견해를 병기해야 하므로, 이
  페이지에서는 기원이 아니라 **적대의 형성**만 서술한다.
- 신약 접점: 요 4:9 "유대인이 사마리아인과 상종치 아니함이러라"(`43, 4`), 요 4:20 "우리 조상들은 이 산에서 예배하였는데"(`43, 4`), 눅 10:33 선한 사마리아인(`42, 10`)

**2. 헤롯 대왕과 헤롯 성전**

- 요약: 복음서의 성전은 헤롯이 대대적으로 개축한 제2성전입니다.
- 상세:
    - 헤롯 대왕의 아버지 안티파테르는 힐카누스 2세의 실세였고, 이두매 출신이었습니다. 헤롯의 유대인 정체성이 늘 의심받은 이유입니다.
    - 헤롯은 B.C. 20/19년경부터 예루살렘 성전을 대대적으로 개축·확장했습니다. 헐고 새로 지은 것이 아니라 **제2성전을 확장한 것**이며, 유대 전통도 이를 제2성전의 연속으로 봅니다.
    - **요 2:20의 "사십육 년"은 완공까지 걸린 기간이 아니라, 그때까지 공사가 진행된 기간입니다.** 복음서의 성전은 여전히 공사 중이었고, 전체 완공은 A.D. 60년대 — 성전이 무너지기 불과 몇 년 전이었습니다.
- 정보 유형: `성경 본문` `역사 자료`
- 신약 접점: 요 2:20 "이 성전은 사십육 년 동안에 지었거늘"(`43, 2`), 눅 1:5 "유대 왕 헤롯 때에"(`42, 1`)
- 주의: 헤롯이 '유대인의 왕'이라는 말에 민감했던 정황과 연결해 마태복음 2장을 읽는 견해가 널리 소개되지만, **마태복음 2장은 헤롯의 혈통을 언급하지 않습니다.** 경쟁자 제거는 혈통과 무관한 왕위 방어로도 설명됩니다. `마 2장 해석: 여러 견해 존재`
- 〔구현 지시 · 화면 출력 금지〕 **"마태복음 2장의 배경이다"라고 단정하지 않는다.** 널리 쓰이는 해석이지만 추론이다. 또한 **헤롯 사후 영토 분할과 아켈라오 폐위는 이 카드가 아니라 카드 3에서 다룬다**(§5-8의 역할 분리 원칙).

**3. 로마의 통치 구조**

- 요약: 총독·분봉왕·세금이 한 화면에 등장하는 이유.
- 상세:
    - 헤롯 대왕이 죽은 뒤 영토가 아들들에게 분할되어, 유대는 아켈라오가, 갈릴리와 **페레아(요단 강 동편)** 는 헤롯 안디바가 다스렸습니다.
    - **아켈라오는 A.D. 6년에 폐위되었고, 그 뒤로 유대 본토는 로마 총독의 직할 통치를 받았습니다.** 그래서 마태복음 2장(아켈라오)과 누가복음 3장(빌라도)은 같은 유대를 말하지만 서로 다른 시대입니다.
    - 갈릴리는 계속 헤롯 가문의 분봉왕이 다스렸습니다. 그래서 복음서에는 총독과 분봉왕이 동시에 등장합니다.
    - 로마에 바치는 세금 문제는 신앙과 정치가 맞부딪히는 지점이었습니다.
- 정보 유형: `성경 본문` `역사 자료`
- 신약 접점: 눅 3:1 "본디오 빌라도가 유대의 총독으로, 헤롯이 갈릴리의 분봉왕으로"(`42, 3`), 마 2:22 아켈라오(`40, 2`), 마 22:17 세금 논쟁(`40, 22`)
- 주의: **눅 2:2의 구레뇨 호적 기사는 연대 논쟁이 있는 구절입니다.** 인용은 가능하나 **연대를 확정하는 근거로 사용하지 않습니다.**
- 〔구현 지시 · 화면 출력 금지〕 **"베뢰아"로 적지 않는다.** KRV에서 "베뢰아"는 마케도니아의 도시다(행 17:10-11 "베뢰아 사람은 … 더 신사적이어서"). 이 페이지의 독자층에게 가장 익숙한 구절 중 하나이므로 혼동을 부른다. **"페레아" 또는 "
  요단 강 동편"** 으로 적는다. (KRV는 페레아를 음역하지 않고 마 19:1에서 "요단 강 건너 유대 지경"으로 서술한다.)

### 6-7. 성경 본문 딥링크

```text
/web/bible/verse?translationId=1&bookOrder={bookOrder}&chapterNumber={chapterNumber}&from=intertestamental
```

> ⚠️ 반드시 `/web/bible/verse`를 사용한다. `/web/bible/chapter`는 **장 선택 목록** 화면이며, `chapter-list.js`가 `translationId`·`bookOrder`만 읽고 `chapterNumber`를 무시하므로
> 특정 장 본문으로 이동하지 않는다. 실제 본문(구절) 읽기 화면은 `/web/bible/verse`이다(`verse-list.js`가 `chapterNumber`를 읽어 해당 장을 연다).

`from=intertestamental`을 붙여 향후 유입 분석에 활용할 수 있게 한다.
기본 번역본은 `translationId=1`(KRV, 개역한글)이다. `HistoryViewResponse.kt:130`의 `KRV_TRANSLATION_ID`와 동일한 값이다.

#### 번역본 표기 주의

이 페이지의 인용 문구는 **KRV(개역한글) 표기 기준**이다. 다른 번역본을 읽는 사용자에게는 표기가 다를 수 있다.

- 특히 아람어 예시로 **"엘리 엘리 라마 사박다니"(막 15:34)를 대표 예시로 쓰지 않는다.** 개역한글은 마가·마태를 동일하게 표기하지만, 원문상 마가는 "엘로이", 마태는 "엘리"이고 개역개정·새번역은 마가를 "엘로이"로 적는다. 게다가 아람어 형태는 "
  엘로이" 쪽이므로, 아람어 예시로 "엘리"를 드는 것은 역효과다.
- 대신 번역본 간 이견이 없는 **막 5:41 "달리다굼"**, **막 7:34 "에바다"** 를 쓴다(§6-2 트랙 1).

## 7. 인터랙션

### 7-1. 통치 세력 상세 패널

- 통치 세력 카드(`button`)를 클릭하면 **그 카드 바로 아래의 상세 패널**이 열린다.
- JS는 대상 패널의 `hidden` 속성을 토글하고 버튼의 `aria-expanded`를 갱신한다. 그 외의 동작은 없다.
- 같은 카드를 다시 클릭하면 닫는다.
- 한 번에 하나만 열리도록 한다(다른 패널이 열려 있으면 닫는다).
- 상세 패널은 데스크톱에서도 고정 사이드바가 아니라 **본문 흐름 안의 확장 영역**이다.

### 7-2. 가로 스크롤

- Ruler Timeline은 좁은 화면에서 가로 스크롤이 발생한다.
- 가로 스크롤 영역에는 **좌우 끝 페이드 힌트**를 둔다. **가로 스크롤이 발생하는 모든 구간(`< 992px`)에 적용**한다(§9).
- 가로 스크롤 영역이 페이지 세로 스크롤을 가로채지 않게 한다(`overscroll-behavior-x: contain`).
- **roving tabindex를 쓰지 않는다.** 카드가 6개뿐이고 전부 네이티브 `button`이므로, 브라우저 기본 Tab 순회로 충분하다. 6개 항목에 roving tabindex를 도입하는 것은 이 페이지에서 가장 복잡한 JS를 만들면서 얻는 것이 거의
  없다.

### 7-3. 초기 상태

- 페이지 진입 시 **어떤 통치 세력 카드도 선택되지 않은 상태**로 둔다. 모든 상세 패널은 `hidden`이다.
- 변화 축은 **항상 펼쳐져 있다**(토글 없음, §5-6).
- URL 쿼리 동기화는 초기 구현에서 하지 않는다. 후속으로 `?ruler=hasmonean` 형태를 지원할 수 있다.

## 8. 접근성

- 타임라인·트랙은 시각적으로 선과 화살표를 쓰더라도 DOM은 읽기 순서가 자연스러운 `section`, `ol`, `li`, `article` 구조로 작성한다.
- Ruler Timeline 카드는 `button`으로 구현하고 `aria-expanded`와 `aria-controls`를 쓴다. **`aria-controls`의 대상은 각 카드 아래의 `id="itpRulerDetail-{slug}"` 패널**이다(§5-5).
- **`aria-live`를 쓰지 않는다.** 패널이 각 카드 아래에 정적으로 존재하고 `hidden`만 토글되므로, 라이브 리전이 필요 없다. 페이지 하단 공용 패널 방식이었다면 필요했겠지만 그 방식을 쓰지 않는다.
- 정보 유형 배지는 **색상만으로 의미를 전달하지 않고 텍스트를 항상 포함**한다.
- 분파 비교 표는 `<table>`로 작성하고 `<th scope="col">`을 지정한다. 카드로 흉내 내지 않는다 — 실제 표 데이터이므로 스크린 리더의 표 탐색이 유효해야 한다.
- 상세 패널은 포커스 트랩이 필요한 모달로 만들지 않는다.
- 모션은 `prefers-reduced-motion: reduce`에서 제거한다.
- 대조 화살표(`→`, `↓`)는 `aria-hidden="true"`로 두고 의미는 라벨 텍스트가 전달한다.

- 다크 모드는 `theme.css`의 시맨틱 토큰(`--color-bg-base`, `--color-text-primary` 등)을 따른다. 하드코딩 색상을 쓰지 않는다.
- Hero를 과하게 만들지 않고 학습 도구처럼 조용하고 정보 밀도 있게 구성한다.
- 카드는 8px 이하 radius를 사용해 기존 카드 UI와 맞춘다.
- 카드 안에 또 다른 카드 형태를 중첩하지 않는다.
- 배지는 작고 읽기 쉬운 pill 형태로 사용하되, 주요 액션 버튼처럼 보이지 않게 한다.
- 5개 배지는 **서로 구분되는 색을 가진다.** `역사 자료`와 `외경·제2정경`을 같은 회색으로 두지 않는다.

### 10-3. `[hidden]` 주의

이 페이지의 유일한 인터랙션은 `panel.hidden` 토글에 올라타 있다(§11-3).

```css
.itp-ruler-detail[hidden] {
  display: none;
}
```

`.itp-ruler-detail`에 `display: flex` / `display: grid` 같은 규칙을 걸면 **`hidden` 속성이 조용히 무력화되어 패널이 항상 열린 상태가 된다.** HTML의 `hidden`은 `display: none`을 UA
스타일시트로 부여하는데, 작성자 스타일시트의 `display` 선언이 이를 덮어쓰기 때문이다. 위 규칙을 반드시 함께 둔다.

### 11-3. JS 구조

JS의 책임은 **상세 패널 토글 하나뿐**이다. 데이터 배열도, 렌더링 함수도 없다.

```javascript
class IntertestamentalPage {
  init() {
    this.buttons = document.querySelectorAll('.itp-ruler-card');
    this.buttons.forEach((button) => {
      button.addEventListener('click', () => this.toggle(button));
    });
  }

  toggle(button) {
    const panel = document.getElementById(button.getAttribute('aria-controls'));
    const willOpen = panel.hidden;
    this.closeAll();
    if (willOpen) {
      panel.hidden = false;
      button.setAttribute('aria-expanded', 'true');
    }
  }

  closeAll() {
    this.buttons.forEach((button) => {
      document.getElementById(button.getAttribute('aria-controls')).hidden = true;
      button.setAttribute('aria-expanded', 'false');
    });
  }
}

document.addEventListener('DOMContentLoaded', () => {
  new IntertestamentalPage().init();
});
```
